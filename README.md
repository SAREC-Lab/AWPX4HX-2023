# AWPX4HX-2023
All weather, PX4, Hexacopter, 2023 Annotated flight logs with descriptions.

Close monitoring of small Uncrewed Aerial Systems (sUAS) is imperative to promptly
detect, diagnose, and potentially mitigate problems that arise during flight. Researchers are
investigating a diverse range of flight problems and solutions through studying sUAS flight
behavior. However, progress is impeded by the lack of publicly available flight logs with
descriptions of anomalies that include annotated time-series data, diagnoses, and explanations
of the observed behavior. We address this lack of data through a longitudinal collection of time-
series flight data for small Uncrewed Aerial Systems (sUAS) running Px4. Our data collection is
in-progress with an anticipated release of the AWPX4HX-2023 (All weather PX4, Hexacopter
flight logs) dataset by December 30, 2023. The dataset contains physical sUAS flight log data
collected using five standard routes executed repeatedly by multiple sUAS and several additional
routes. The flights are collected across multiple seasons and weather conditions. Metadata
collected for each flight includes weather, flight plans, battery details, payload descriptions,
and alerts or error messages raised by the Ground Control Station. Each flight log is analyzed
and subsequently annotated with ground truth anomalies and corresponding explanations of
the observed flight behavior. The current data set is available for immediate use, but will be
continually appended until its official release in December 2023. This paper describes the data
we are collecting, and suggested use-cases.
